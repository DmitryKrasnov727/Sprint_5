Спринт 5 UI тестироание.
Автотесты для сервиса Stellar Burgers. https://stellarburgers.education-services.ru/

- в папке [tests] файлы с тестами;
- файл [conftest] фикстуры;
- файл [locators] локаторы;
- файл [data] тестовые данные полей ввода;
- файл [helpers] функции, генерирующие рандомные данные для тестов регистрации;
- файл [README] описание.

[test_registrarion] тесты проверяют позитивные и негативные сценарии при заполнении полей формы регистрации;

[test_authentication] тесты проверяют четыре сценария аутентификации в приложении;

[test_navigate_to_constructor] тесты проверяют переход в конструктор бургера из личного кабинета пользователя;

[test_navigate_to_personal_account] тест проверяет переход в личный кабинет с главной страницы;

[test_switch_blocks_on_constructor] тесты проверяют переключение разделов в меню конструктора;

[test_logout] тест проверяет выход из аккаунта по кнопке «Выйти» в личном кабинете;


Запуск всех тестов в терминале: `pytest -v`.
